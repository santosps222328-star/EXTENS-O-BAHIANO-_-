EXTENSÃO BAHIANO >_♡

Central de idiomas da extensão BAHIANO UI.

Idiomas planejados

- Português (Brasil): pt-BR
- Português (Portugal): pt-PT
- Inglês: en
- Indonésio: id

Segurança

Os idiomas serão armazenados em arquivos JSON. A extensão deverá validar os arquivos recebidos e nunca executar conteúdo baixado como código.

Importante

Este repositório contém os arquivos de tradução da extensão. A integração com o código da extensão será feita e testada separadamente.
